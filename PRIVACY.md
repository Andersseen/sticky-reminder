# Sticky Reminder privacy policy

**Effective date:** August 18, 2026  
**Last updated:** August 18, 2026

Sticky Reminder is a local-first browser extension. It does not collect, sell,
share or transmit personal data. It has no accounts, analytics, advertising,
remote API or backend service.

## Data the extension handles

When you create a reminder, the extension handles the information you enter:

- reminder title
- optional reminder note
- scheduled date and time
- repeat setting and completion state

This information is stored only in the browser's local extension storage on
your device. It is used only to display, schedule and notify you about your
reminders. Sticky Reminder does not send it to the developer or to third
parties, and does not use it for advertising, profiling or credit decisions.

The extension does not read your browsing history, page content, location,
contacts or activity on other websites. It does not request host permissions.

## Permissions

Sticky Reminder requests only these browser permissions:

- **alarms** — schedules a reminder for its due time.
- **notifications** — displays the reminder through the browser's native
  notification system.
- **storage** — saves reminders in local extension storage on your device.

## Retention and deletion

Reminder data stays in local extension storage until you delete the reminder,
clear the extension's data or uninstall the extension. The developer cannot
access or recover this data because it is never received by a developer-run
service.

Browser backup, enterprise-management or device-sync features outside Sticky
Reminder's control may handle local browser data according to the browser or
device provider's own policies.

## Children's privacy

Sticky Reminder does not knowingly collect personal information from anyone,
including children, because it does not transmit or receive user data.

## Changes to this policy

Material changes will be published in this repository and on the public policy
page with a new “Last updated” date. A change that requires new extension
permissions or data handling will also be disclosed in the relevant store
listing and release notes.

## Contact

For privacy questions, open a
[privacy issue](https://github.com/Andersseen/sticky-reminder/issues/new?labels=privacy&title=Privacy%20question)
without including sensitive reminder content. Security vulnerabilities should
be reported privately through the repository's
[security advisory form](https://github.com/Andersseen/sticky-reminder/security/advisories/new).
